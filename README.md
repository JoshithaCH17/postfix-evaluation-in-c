# Postfix Evaluation in C

A stack-based C program to evaluate
postfix expressions.

## Features
- Evaluates postfix expressions
- Supports +, -, *, / and %
- Uses stack operations
- Handles invalid expressions
- Checks division by zero

## Example

Input:
23*5+

Output:
Result = 11

## Concepts Used
- Stack
- Arrays
- Postfix Expressions
- Arithmetic Operators

## Limitations
- Single-digit operands only
- No spaces
- Integer arithmetic only

## How to Run

Compile:
gcc postfix_evaluation.c -o postfix_evaluation

Run on Windows:
.\postfix_evaluation.exe

## Language
C
